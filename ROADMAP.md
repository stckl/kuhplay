# KuhPlay – Roadmap & aktueller Stand

**Letzte Aktualisierung:** 2026-10-29 (TODO.md **Phasen 0–6 vollständig erledigt** – Phase 6 = Show-Mode & Feinschliff – inkl. Phase 0b Programm-Icon; UI-Überarbeitung abgeschlossen)

## ✅ Fertig (getestet, 460 Tests grün)

- **Screen-Layout:** Model, Editor (Karte, Drag, Snap-to-Display, Resize 4 Ecken), Drehung 0/90/180/270°, pixelgenau
- **Testbilder:** Grid, SolidColor, ColorBars, **LedWall** (nummeriertes Schachbrett, Kachelgröße einstellbar, 1px Rahmen, 1px Kreis, Pixelskala umlaufend, abgedunkelte Screen-Farbe)
- **Farbcodierung:** automatisch pro Screen-Index (8 Farben), recolor nach Löschen
- **Persistenz:** ShowDocument mit Screens + Stages (abwärtskompatibel)
- **Stage→Screen:** Zuordnung, Hardware-Ausgabe (Vollbild-Viewports)
- **Engine:** Compositor zeichnet Testbilder, Mock + Real Engine
- **Remote-Steuerung (integriert):** Web-Remote (HTTP + WebSocket, eingebettete HTML-UI) + Companion TCP (JSON-lines), bidirektional – gemeinsame Typen in `src/remote/mod.rs`
- **Remote-Integration:** Server-Start in `ShowApp::new()` (eigener tokio-Runtime, Env-Konfig `KUHPLAY_REMOTE*`), Commands geroutet wie UI-Aktionen, Engine-Events → `RemoteEvent`-Broadcast, Status-Push (sofort bei Änderung + 1×/s)
- **Decklink Output (Modul + Engine-Anbindung):** `src/engine/decklink.rs` – ffmpeg-Subprocess, RGBA-Frames → `decklink`-Muxer (`ffmpeg_decklink_args`, `DecklinkOutput::push_frame`, Drop killt den Prozess). **Angebunden an `RealMediaEngine`:** Compositor-Frames der konfigurierten Stage werden im Decklink-Takt gepusht (kontinuierlicher SDI-Stream, schwarzes Frame bis zum ersten Composite; Push-Fehler deaktiviert die Ausgabe statt zu spammen). Config via `KUHPLAY_DECKLINK_DEVICE` / `_STAGE` / `_WIDTH` / `_HEIGHT` / `_FPS` / `_PIXFMT` (Stage-Auflösung muss zur Karte passen – Warnung bei `ConfigureStage`)
- **Companion JS-Modul:** `companion/kuhplay/` (manifest.json + index.js + package.json) – Actions (GO/Panic/Pause/Resume/Reset/GoTo/Arm/Show-Mode), Variablen (Show-Name, Playhead, Standby, …), Feedback „Cue läuft"
- **Decklink-Scaling:** Stage-Canvas ≠ Karten-Auflösung wird per Nearest-Neighbor skaliert (`scale_nearest` in `src/engine/decklink.rs`, im `tick_decklink` verdrahtet – statt Disable bei Mismatch)
- **Cue-Farben:** `Cue.color: Option<[u8;3]>` (serde-abwärtskompatibel, 8er-Palette `CUE_COLORS`), Farbpunkt in der Cue-Liste (Name-Spalte), Farb-Editor im Inspector (Swatch + ✕ zum Löschen)
- **OSC-Steuerung:** `src/remote/osc.rs` (rosc, UDP) – In: `/kuhplay/go|panic|pause|resume|reset|goto|arm|showmode|status`; Out: Events → `/kuhplay/status`, `/kuhplay/cue/*`, `/kuhplay/playhead|standby|showmode|panicked|pong`. Env: `KUHPLAY_OSC=off`, `KUHPLAY_OSC_PORT` (Default 9000), `KUHPLAY_OSC_OUT` (`host:port` oder `off`, Default 127.0.0.1:9001). Eigene std-Threads (blocking UDP), wired in `RemoteServers`
- **MIDI-Steuerung:** `src/remote/midi.rs` (midir, CoreMIDI/ALSA) – Note-On-Map: Note 0=GO, 1=Panic, 2=Pause, 3=Resume, 4=Reset (Channel egal, Velocity 0 = Note-Off ignoriert). Env: `KUHPLAY_MIDI=off`, `KUHPLAY_MIDI_DEVICE` (Namens-Substring, sonst erstes Device). Callback-basiert (kein Server-Thread); kein Device → nur Warnung (Graceful Degradation)
- **Waveforms:** `src/engine/waveform.rs` – symphonia-Dekodierung → Mono-Mixdown → min/max-Peaks pro Bucket (512, normalisiert −1..1), `WaveformCache` (Pfad → Peaks, Fehler gecacht). Inspector: Waveform-Vorschau (egui-Painter, 48 px) für Audio/Video-Cues mit lokaler Datei, inkl. Dauer/Sample-Rate-Tooltip
- **Audition-Mode:** `ShowApp.audition_mode` (Workspace-Menü → Checkbox, AUDITION-Badge im Masthead); `dispatch` strippt `stage` aus `Play`/`PlayHtml`/`PlaySlideShow` (Video ohne Stage-Ziel, Audio unverändert – siehe `apply_audition`)
- **HTML5-WebView (wry):** `src/engine/webview_backend.rs` – JSON-lines IPC über stdio (`{"load":…}`/`{"eval":…}`/`{"push_json":…}`/`{"snapshot":{…}}`/`{"close":true}` in, `{"loaded|js_executed|json_received|frame|error":…}` out), `WebviewInstance` = ein Subprocess pro Cue (Reader-Thread, Drop killt). Binary `src/bin/kuhplay-webview.rs` (tao + wry, WKWebView; eigener Prozess, weil tao den Main-Thread braucht) hinter Cargo-Feature `webview` (`cargo build --features webview`). Engine: `webview_binary()` (`KUHPLAY_WEBVIEW_BIN` oder neben current_exe) → `RealMediaEngine` nutzt echtes Backend, sonst virtueller Fallback; `EvalJs`/`PushJson` gehen an den Subprocess, WebView-Fehler → `EngineEvent::Error`
- **OSC/MIDI konfigurierbare Mappings:** OSC-Präfix via `KUHPLAY_OSC_PREFIX` (Default `/kuhplay`, In-Adressen relativ zum Präfix, Out-Events `{prefix}/status` usw.; `normalize_prefix` für führendes `/` und trailing `/`). MIDI-Noten-Map via `KUHPLAY_MIDI_MAP` (`go=36,panic=37,…`; unbekannte Keys/Noten >127 werden ignoriert) – `MidiNoteMap` in `src/remote/midi.rs`, durchgereicht durch `RemoteConfig` → `ShowApp`
- **Mehrkanal-Audio-Routing:** `AudioRoute` += `first_channel` (1-basiert, 0 = Default; `#[serde(default)]` abwärtskompatibel; `validate()` prüft Patch-Ende ≤ 16 Kanäle). `AudioBackend::add_voice(…, route)` dekodiert in das **Cue-Kanal-Layout**; Mixer patcht Voice-Kanal `i` → Device-Kanal `first_channel+i` (am Rand abgeschnitten) mit Constant-Power-Pan (`pan_gains`, unity in der Mitte) auf Patch-Kanälen 1+2. Reine Mixer-Funktion `mix_voice` (unit-getestet). Inspector: „Patch"-Row (Kanäle 1–16, ab 0–16, Pan-Slider, Reset auf Device-Default)
- **WebView-Compositing:** HTML5-Cues landen im Stage-Compositor – Engine fordert nach `Loaded` alle 100 ms einen Snapshot an (`{"snapshot":{"width":W,"height":H}}`, Größe = Stage-Canvas), macOS nativ via WKWebView `takeSnapshot` (objc2, `WryWebView` ist eine WKWebView-Subklasse; NSImage → TIFF → PNG → RGBA), andere Plattformen kooperativ via Page-Canvas (`canvas[data-kuhplay-capture]` bevorzugt → `toDataURL`). Antwort `{"frame":{"width","height","rgba_b64"}}` → `WebviewEvent::Frame` → Frame-Store → Compositor (Html-Kind in `surfaces_of_stage`/`composite_dirty_stages`). Snapshot-Fehler: 1× `EngineEvent::Error`, dann Backoff nach 3 Fehlschlägen. Deps: `base64` (neu, direkt) + macOS-optional `objc2-foundation`/`objc2-app-kit`/`objc2-web-kit`/`block2` (Versionen passend zu wry 0.47 – keine neuen Crates im Tree)
- **Programm-Icon:** `icon.png` (Projekt-Root) via `include_bytes!` eingebettet → `gui::app_icon()` (PNG→RGBA) → `ViewportBuilder::with_icon` in `main.rs` (fehlende Datei = Build-Fehler)

## Architektur-Notizen

- **Remote-Protokoll:** JSON-lines über TCP (Companion) + WebSocket (Web-Remote), gemeinsame Typen in `src/remote/mod.rs`
- **Bidirektional:** App pusht `RemoteEvent` (Status, Cue-Events) an alle Clients; Server cachen `RemoteEvent::Status` für `/api/status` und neue Verbindungen
- **Decklink:** ffmpeg mit `-f decklink`, Input: rawvideo/rgba Pipe vom Compositor (Stage-Canvas wird bei Größen-Mismatch per Nearest-Neighbor skaliert); Env: `KUHPLAY_DECKLINK_DEVICE` (unset = aus), `KUHPLAY_DECKLINK_STAGE` (Default „Stage 1"), `KUHPLAY_DECKLINK_WIDTH/HEIGHT/FPS/PIXFMT` (Default 1920×1080@25 uyvy422)
- **Ports:** Web-Remote 8080, Companion 9999, OSC 9000 (Out 127.0.0.1:9001) – konfigurierbar via `KUHPLAY_REMOTE_WEB_PORT` / `KUHPLAY_REMOTE_COMPANION_PORT` / `KUHPLAY_OSC_PORT` / `KUHPLAY_OSC_OUT` / `KUHPLAY_OSC_PREFIX`, abschaltbar via `KUHPLAY_REMOTE=off` / `KUHPLAY_REMOTE_WEB=off` / `KUHPLAY_REMOTE_COMPANION=off` / `KUHPLAY_OSC=off` / `KUHPLAY_MIDI=off`
- **MIDI-Mapping:** `KUHPLAY_MIDI_MAP` = `go=<note>,panic=<note>,pause=<note>,resume=<note>,reset=<note>` (Default 0–4; unbekannte Keys/Noten >127 ignoriert)
- **WebView:** Subprocess `kuhplay-webview` (Feature `webview`), JSON-lines über stdio; Binary via `KUHPLAY_WEBVIEW_BIN` oder neben dem App-Executable. Snapshot-IPC für Compositing: `{"snapshot":{…}}` in, `{"frame":{…}}` (RGBA/base64) out – macOS nativ (WKWebView `takeSnapshot`), sonst JS-Canvas-Fallback; Engine-Backoff nach 3 Snapshot-Fehlern
